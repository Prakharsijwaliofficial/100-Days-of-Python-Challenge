# 🔐 Day 29 - Password Manager GUI

## 📌 Project Overview

Day 29 of the **100 Days of Code: Python Bootcamp by Dr. Angela Yu**.

In this project, I built a **Password Manager desktop application** using Python's **Tkinter GUI library**.

The application allows users to:
- Generate secure random passwords
- Save website login credentials
- Store passwords locally in a text file
- Automatically copy generated passwords to the clipboard

This project helped me understand **GUI development, file handling, random password generation, and list comprehension** in Python.

---

# 🚀 Features

## 🔑 Password Generator

- Generates random secure passwords
- Allows customization of:
  - Letters
  - Numbers
  - Symbols
- Uses Python's `random` module
- Automatically shuffles generated characters
