### 2️⃣ NATO Phonetic Alphabet Project

This project:

- Reads the `nato_phonetic_alphabet.csv` file.
- Converts the CSV into a Python dictionary.
- Takes a word from the user.
- Returns the corresponding NATO phonetic code words.

### Example

**Input**

```
Enter a word: CAT
```

**Output**

```
['Charlie', 'Alfa', 'Tango']
```
