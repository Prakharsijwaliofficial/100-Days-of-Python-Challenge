# 🏋️ Day 38 — Workout Tracking API

A Python workout tracking application built as part of the **100 Days of Code: The Complete Python Pro Bootcamp by Angela Yu**.

This project uses APIs to understand natural-language exercise descriptions, calculate workout information, and automatically store the results in a Google Sheet using Sheety.
