**# 🍅 Day 28 - Pomodoro Timer | 100 Days of Python

## 📖 Overview

Welcome to **Day 28** of my **100 Days of Python** journey! 🚀

In this project, I built a **Pomodoro Timer** using **Python** and **Tkinter**. The Pomodoro Technique is a time management method that alternates focused work sessions with short and long breaks to improve productivity.

This project introduced me to event-driven programming, countdown timers, and building interactive desktop applications with Tkinter.

---

## ✨ Features

* 🍅 25-minute work sessions
* ☕ 5-minute short breaks
* 🌴 20-minute long break after every four work sessions
* ⏳ Live countdown timer
* ✅ Progress checkmarks after each completed work session
* 🔄 Reset button to restart the timer
* 🎨 Clean and simple graphical user interface (GUI)

---

## 🛠️ Technologies Used

* **Python 3**
* **Tkinter**
* **Math Module**

---

## 📚 Concepts Learned

During this project, I learned about:

* Creating desktop GUI applications with Tkinter
* Working with the `Canvas` widget

* Cancelling scheduled events with `after_cancel()`
* Countdown timer implementation
* Global variables
* Functions and callbacks
* Updating widgets dynamically with `.config()` and `.itemconfig()`

## 💡 About the Pomodoro Technique

The Pomodoro Technique is a productivity method created by Francesco Cirillo.

Typical cycle:

* 🍅 25 minutes of focused work
* ☕ 5 minutes short break
* 🔁 Repeat four times
* 🌴 Take a 20-minute long break
